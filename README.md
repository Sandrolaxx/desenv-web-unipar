# Título Principal

Removi tudo!

Criação de branch:

```bash
git checkout -b feat/WEB-123
```

Adicionando na Staging Area
```bash
git add .
```

Realizando commit
```bash
git commit -m "fix: melhorias documentação"
```

Subindo para upstream (github)
```bash
git push --set-upstream origin feat/WEB-123
```
